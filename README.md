# Ecliptica-Overlay
shows boss information and map phase as well as agro and option to enable osc chat box so others can see.

This project has no involvement with Vrchat or Ecliptica it self this is fully a project of my own doing.

Boss information comes from the wiki https://ecliptica.miraheze.org/wiki everything is read from the vrchat logs.
